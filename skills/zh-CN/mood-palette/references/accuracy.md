# 准确性与命名说明

本库按 12 个主题整理 100 组三色组合。原始组内重排和近似重复保留，100 组不等于 100 套互不重复的独立颜色；检索结果会去除近似重复。

主题名按颜色关系统一重新命名，仅作检索标签。编号、情绪、用途和用量建议为应用说明；重命名不表示参考色组为原创。日常色名由颜色特征粗分得到，并非标准色票名称。

- `printed_hex`：`cream-sky-01` 的三个值按可辨认的 HEX 标签转录。
- `image_sample`：其余 99 组为图像色块内部 RGB 采样的近似值。压缩、光影与色彩处理会影响结果，不等同于印刷源值或校准测量。
- 三色的记录顺序不表示主辅色或面积比例。主色、60/30/10 等比例都是应用建议。
- UI 补充的深浅色与中性色标注“应用派生”，保持原色组 HEX 不变。对比度需针对实际配对计算。

100 张配色图片均由 JSON 中的三色 HEX 独立绘制，统一为 1200×552 的三栏纯色色卡，附 HEX 与编号。图片不包含参考整图、裁片、纹理、文字或水印，也不使用生成模型。内部纯色色块与记录 HEX 逐一核对；圆角、边框和文字是展示样式，不属于配色组合。

公开数据只包含应用所需的编号、主题、色值、图片相对路径和取值方法；不附任何参考原图或其裁片、来源链接、采集记录或个人信息。
