# Accuracy and naming

The catalog contains 100 three-color records in 12 themes. Reordered and near-duplicate records remain in the catalog; this does not mean 100 unique color sets. Search removes approximate duplicates.

Theme names were newly assigned as organizational labels based on color relationships. IDs, moods, use cases, and ratios are application guidance. Renaming does not imply original authorship of reference color combinations. Everyday color names are approximate search labels, not standardized swatch names.

- `printed_hex`: the three values in `cream-sky-01` were transcribed from legible HEX labels.
- `image_sample`: the other 99 records contain approximate RGB samples from the interior of image swatches. Compression, lighting, and image color processing can affect them; they are not calibrated measurements or print source values.
- Stored order implies neither color roles nor area ratios. Suggested primary colors and ratios such as 60/30/10 are application decisions.
- Mark additional UI shades or neutrals as application-derived and preserve original HEX. Measure contrast for the actual color pairs.

All 100 palette images are independently rendered from catalog HEX values as 1200×552 cards with three equal-width solid swatches, HEX labels, and an ID footer. They contain no reference images, crops, textures, captions, or watermarks and do not use an image-generation model. Interior swatch pixels are checked against the stored HEX. Rounded corners, borders, and text are display styling rather than palette colors.

Public records contain only the required ID, theme, colors, relative image path, and method. Reference images and their crops, source links, collection records, and personal information are excluded.
