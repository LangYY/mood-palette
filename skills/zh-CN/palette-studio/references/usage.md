# 调用示例

直接输入 `$palette-studio` 加任务描述，也可以说“用Palette Studio……”。下列句子是自然语言示例，不是新增的斜杠命令或脚本子命令。

## 最短用法

```text
$palette-studio 给我的茶品牌推荐一组配色。
```

按用户指定数量直接展示库内预渲染的三栏色卡；未给数量时默认 5 张。图片来自每条记录的 `image` 字段，附普通颜色描述与建议主色，编号和 HEX 作补充。直接复用图片，不重新画检索图；用户只要色值时再返回文字。主题、尺寸和格式都可省略，由当前任务补全。只想看目录时说“列出配色主题”，不会开始生图。

不记主题名也可以直接说：

```text
我想要一组以蓝色为主题的配色，推荐 5 个组合供我选择。
给我推荐 5 组浅一点、低饱和的粉红色配色。
选第 3 组，接下来用它生成一张海报。
```

先按普通色名和色彩特征检索库内组合，展示候选后等待选择。候选不足时报告实际数量。具体检索条件和结果格式见 [日常颜色检索](search.md)。

## 选色与对比

```text
$palette-studio 给阅读网站推荐两组安静的配色，说明背景、正文和强调色，先不要改文件。

$palette-studio 对比奶油晴空和雨幕青灰，哪组更适合天气工具？只给配色建议。
```

只给建议，不调用生成工具或修改项目。指定主题名会按任务所需数量从该主题选择具体编号；需要完全复现时指定编号。

## 实际生图与只写提示词

```text
$palette-studio 用 cream-sky-01 生成一张陶器静物插画，横版 4:3，无文字，用 imagegen。

$palette-studio 用雨幕青灰生成一张摄影展海报，竖版，标题是 RAIN STUDIES。

$palette-studio 用苔绿茶褐写一条茶具产品图提示词，先不要生图。
```

前两条交付实际图片与提示词；第三条只交付提示词。HEX 指导配色关系，不承诺逐像素一致。生成工具不可用时说明限制。

## UI：变量、示意图与改现有页面

```text
$palette-studio 用 moss-tea-05 给茶品牌网站输出 CSS 颜色变量和对比度，先不做页面。

$palette-studio 用薄荷软糖生成一张花店首页 UI 示意图，桌面横版，用 imagegen。

$palette-studio 用 rain-slate-01 给当前仪表盘改色，保留布局、内容、交互和现有变量命名。
```

分别交付变量、静态示意图、项目代码修改。静态 UI 图不等于可运行页面；代码改色不顺带重做布局。纯检查可说“只检查当前文字和按钮的对比度，不改色”。

变量示例（`moss-tea-05`）：背景 `#D6C78C`、主按钮 `#684936`、装饰强调 `#86A126`；正文派生 `#302B20`、表面及按钮文字派生 `#F7F0DA`。不透明实色计算：正文/背景约 8.32:1，按钮文字/主按钮约 7.10:1，主按钮/背景约 4.78:1。这些数值只适用于所列配对；项目实际使用时重算。

## 批量生成

```text
$palette-studio 用 10 组不同配色，分别生成插画、UI 界面和海报各 10 张，共 30 张，用 imagegen。相同编号跨用途复用，附原图、提示词和图集。

$palette-studio 用奶油晴空生成 3 张不同构图的茶具产品图，保持同一编号，横版，无文字。
```

第一条对应“10 个编号 × 3 种用途 × 每项 1 张”；第二条对应“1 个编号 × 1 种用途 × 3 种构图”。按清单计数独立原图，图集只负责浏览。未指定用途类别时，根据上下文给出具体分配再执行。

## 和其他设计工作搭配

```text
用 $palette-studio 的 moss-tea-05 配色，沿用项目当前设计系统，实现茶品牌首页。

继续用刚才那组颜色，给设置页改色，沿用已选语义变量。
```

配色库提供色组与角色，布局、字体、组件和产品流程由项目约束及相应设计流程负责。可以搭配已安装的设计 Skill；不要求安装额外项目。明确的品牌约束优先，遇到无法同时满足的颜色要求再说明冲突。

## 脚本取数（可选）

在包含 `SKILL.md` 的目录运行：

```bash
python3 scripts/palette.py --list
python3 scripts/palette.py moss-tea-05
python3 scripts/palette.py --search 蓝色 --limit 5
python3 scripts/palette.py --search 粉红色 --lightness light --saturation muted --limit 5
python3 scripts/palette.py --contrast '#302B20' '#D6C78C'
```

`--list` 列出 12 个主题，编号查询返回三色和取值方法；`--search` 推荐真实候选并去除近似重复；`--contrast` 只计算不透明 sRGB 实色。这些是脚本命令，不需要用户在日常调用时手动运行。
